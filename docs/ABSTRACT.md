# Research Abstract: NeuroFuzz

### Structured Coverage-Guided Fuzzing via State-Sequence-Aware Frontier Exploration and Contextual Mutation

**Abstract**  
Coverage-guided fuzzing has proven highly effective at discovering software vulnerabilities, yet conventional mutation-based engines struggle when testing structured, stateful network protocols. In such targets, advancing to deeper program states requires preserving multi-field prefixes while simultaneously appending valid transition tokens; unguided point mutations corrupt structural boundaries with overwhelming probability, while crossover cannot synthesize novel tokens absent from the initial corpus. 

We present **NeuroFuzz**, a coverage-guided fuzzing framework tailored for structured protocol exploration. NeuroFuzz introduces **StateFrontier**, an algorithm that indexes seed inputs by their deepest validated state machine depth and systematically synthesizes terminal boundary extensions using protocol grammar tokens. This core mechanism is augmented by contextual mutation bandits conditioned on seed structural features, compatibility-aware field splicing, runtime delimiter discovery, and a persistent execution harness sustaining over 870 executions per second on Windows x86_64.

We conduct a rigorous empirical ablation study comprising 55 trials and 1,375,000 executions across an 11-configuration matrix with paired random seeds. Our evaluation demonstrates that `StateFrontier` breaks the sequential state barrier, achieving a 100% reach rate for terminal protocol states (Depth 19) in under 350 iterations—a threshold unguided fuzzers failed to reach in any trial over 25,000 iterations—and providing a $+10.20 \pm 1.30$ unit coverage increase across all seeds. Furthermore, component ablations reveal that structured field splicing (+2.40 units) and contextual mutation (+1.40 units) provide consistent coverage breadth, whereas an online linear bandit seed scheduler imposed a 34% throughput penalty without improving coverage or depth in the presence of frontier exploration. Finally, we show that unguided random search discovers over 2× more unique crashes by corrupting shallow parser logic, illustrating a fundamental tradeoff between syntactic crash elicitation and deep-state logic exploration.
